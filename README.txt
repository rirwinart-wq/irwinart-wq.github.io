IRWIN ART — SIMPLE HTML LANDING PAGE

Files:
- index.html: one-page landing website with a single store button linking to https://irwinart.company.site

Before publishing:
1. Open index.html in a browser to preview.
2. Replace the decorative placeholder artwork in the CSS/HTML with your own painting if desired.
3. This folder can be uploaded to a static host such as Cloudflare Pages.

Domain safety:
- Do not cancel Hostinger or change nameservers until you have confirmed where irwinart.org registration, DNS, and any email service are managed.
- Cloudflare Pages supports static HTML and custom domains. Using the root domain may require changing nameservers; a subdomain can often be connected with a CNAME while leaving other DNS records at the current provider. Follow the exact records shown by the hosting dashboard.
